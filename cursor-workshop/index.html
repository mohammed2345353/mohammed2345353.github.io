واجهة حيّة تبني نفسها أمام الزائر خطوة بخطوة

نموذج Cursor Workshop يدمج حركة المؤشرات الملونة، قياسات الأبعاد الحية، والكتابة التدريجية في محرك خفيف قابل لإعادة الاستخدام في مواقعك.

رسم الأطر والقياسات اللحظية

يتحرك كل مؤشر إلى زاوية العنصر أولاً ثم يسحب الإطار مع إظهار العرض والارتفاع بالبكسل قبل كشف المحتوى النهائي.

🧲

النسخ المرئي وخطوط المحاذاة الذكية

يسحب المؤشر نسخة مرئية من البطاقة المجاورة مع عرض خطوط المحاذاة الأفقية وقياس الفجوة والمسافة بالبكسل أثناء السحب.

SECTION 02 • يُبنى عند الوصول بالتمرير أو أثناء الجولة التلقائية

افصل المحرك عن المحتوى: أضف التأثير لأي صفحة بسمات HTML فقط

لا حاجة لتعديل ملفات JavaScript عند تغيير التصميم؛ يقرأ المحرك سمات data-cw-* ويرتب المهام المتوازية والمتتابعة تلقائياً.

🎛️

تزامن دقيق بين الصوت والسرعة والإيقاف

توليد فوري لنقرات الكتابة والسحب والمحاذاة عبر Web Audio API. عند الإيقاف المؤقت أو تسريع العرض إلى 2× و3× يتكيف الصوت والحركة في نفس اللحظة.

دليل تشغيل Cursor Workshop وتحديد عناصر جديدة

يتكون النموذج من 4 ملفات مستقلة تعمل محلياً أو عبر GitHub Pages بدون خادم أو مكتبات خارجية:

  • index.html — هيكل الصفحة والمحتوى مع سمات data-cw-* لتحديد العناصر.
  • styles.css — تنسيقات مساحة الرسم الداكنة، المؤشرات، القياسات، وشريط التحكم اللمسي.
  • cursor-engine.js — محرك التوقيت والمؤشرات والجولة التلقائية ومراقب التمرير.
  • audio-engine.js — مولّد الأصوات الإجرائي عبر Web Audio API المتزامن مع سرعة العرض.

طريقة تحديد عناصر جديدة في أي صفحة HTML:

<!-- 1. حدّد القسم ليتم بناؤه تلقائياً أو عند الوصول إليه بالتمرير -->
<section data-cw-section="1">

  <!-- 2. سحب إطار صورة وكشفها (الخطوة 1) -->
  <div data-cw-item data-cw-step="1" data-cw-action="draw-image" data-cw-cursor="cyan">
    <div class="cw-avatar-inner">...</div>
  </div>

  <!-- 3. رسم عنوان وكتابة النص تدريجياً بالتوازي (نفس رقم الخطوة 1) -->
  <div data-cw-item data-cw-step="1" data-cw-action="draw-type" data-cw-cursor="violet">
    <h1 data-cw-type data-ar="عنوان بالعربية" data-en="English Title"></h1>
  </div>

  <!-- 4. رسم بطاقة ثم سحب نسخة مرئية منها إلى بطاقة ثانية -->
  <article id="card-a" data-cw-item data-cw-step="2" data-cw-action="draw-card" data-cw-cursor="amber">...</article>
  <article data-cw-item data-cw-step="3" data-cw-action="clone-card" data-cw-clone-from="#card-a" data-cw-cursor="amber">...</article>

</section>
