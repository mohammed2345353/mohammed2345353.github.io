# Cursor Workshop — نموذج واجهة تبني نفسها بمؤشرات ملونة

نموذج ويب تفاعلي مستقل يعرض واجهة مستخدم تبني نفسها أمام الزائر عبر مجموعة مؤشرات ملونة، قياسات أبعاد حية، خطوط محاذاة ذكية، وكتابة تدريجية متزامنة مع مؤثرات صوتية مولّدة برمجياً عبر **Web Audio API**. صُمم هذا النموذج بهيكلية مفصولة تمهيداً لتحويله إلى مكوّن قابل لإعادة الاستخدام في أي موقع ويب بدون خادم أو مفاتيح API أو مكتبات خارجية.

## 1. تشغيل النموذج محلياً وعلى GitHub Pages

النموذج لا يتطلب أي عملية بناء (Build) أو خادم خلفي أو حزم خارجية:

1. **التشغيل المحلي المباشر:** افتح الملف `index.html` مباشرة في أي متصفح حديث (Chrome, Edge, Firefox, Safari)، أو شغّل خادماً محلياً بسيطاً إن رغبت عبر:
   ```bash
   python3 -m http.server 8080
   ```
2. **النشر على GitHub Pages:** ارفع محتويات المجلد (`index.html`, `styles.css`, `cursor-engine.js`, `audio-engine.js`, `README.md`) إلى مستودع GitHub وفعّل GitHub Pages من الفرع الرئيسي ليعمل مباشرة.

## 2. الملفات المسؤولة عن الحركة والصوت والتنسيق

تعتمد معمارية المشروع على فصل المحتوى عن منطق التوقيت والصوت:

| الملف | المسؤولية والدور التقني |
| :--- | :--- |
| `index.html` | هيكل الصفحة ومحتواها الثنائي اللغة (عربي/إنجليزي) مع تحديد العناصر القابلة للبناء عبر سمات `data-cw-*` فقط دون خلط منطق الحركة بالمحتوى. |
| `styles.css` | تصميم مساحة الرسم الهندسية الداكنة، المؤشرات الملونة، شارات القياس (`W × H px`)، خطوط المحاذاة، شريط التحكم المتجاوب والصالح للمس، ودعم استعلام `@media (prefers-reduced-motion: reduce)`. |
| `cursor-engine.js` | المحرك المستقل (`CursorWorkshopEngine`) المسؤول عن قراءة سمات HTML، جدولة الخطوات المتوازية والمتتابعة، حساب الإحداثيات اللحظية، الإيقاف المؤقت والاستئناف الدقيق من نفس الموضع، التحكم بالسرعات (`1×`, `2×`, `3×`)، مراقبة التمرير (`IntersectionObserver`)، وتنفيذ الجولة التلقائية (`Auto Tour`). |
| `audio-engine.js` | محرك الصوت الإجرائي (`CursorAudioEngine`) المبني على `Web Audio API` لتوليد نقرات الكتابة، نبضات السحب، رنين المحاذاة (`Snap Ping`)، ونغمة اكتمال العرض بالتزامن التام مع سرعة الحركة وحالة الإيقاف. |

## 3. طريقة تحديد عناصر جديدة في أي صفحة HTML

لإضافة التأثير إلى عناصر جديدة أو صفحة ثانية دون تعديل `cursor-engine.js`:

1. **تحديد الأقسام (`data-cw-section`):**
   ضع السمة `data-cw-section="1"` على القسم الأول (يبدأ تلقائياً عند فتح الصفحة)، و`data-cw-section="2"` أو `3` على الأقسام التالية لتبدأ عند الوصول إليها بالتمرير أو أثناء الجولة التلقائية:
   ```html
   <section data-cw-section="2">
     <!-- العناصر القابلة للبناء هنا -->
   </section>
   ```

2. **تحديد العناصر القابلة للبناء (`data-cw-item`):**
   أضف الصنف المبدئي `cw-pending` والسمات التالية على أي عنصر تريد أن يبنيه المؤشر:
   - `data-cw-item`: لتسجيل العنصر في المحرك وعدّاد العناصر المكتملة.
   - `data-cw-step="1"`: رقم الخطوة داخل القسم. **العناصر التي تحمل نفس رقم الخطوة داخل القسم الواحد تُبنى بالتوازي** في نفس اللحظة، بينما تنتظر الخطوة `2` اكتمال الخطوة `1`.
   - `data-cw-cursor="cyan | violet | amber | emerald"`: اختيار لون واسم المؤشر المنفّذ للحركة.
   - `data-cw-duration="2200"`: (اختياري) مدة بناء العنصر بالملي ثانية عند السرعة `1×`.
   - `data-cw-action`: نوع الحركة المطلوبة، ويدعم الأنواع الأربعة التالية:
     - `draw-image`: يتحرك المؤشر إلى زاوية العنصر، يسحب الإطار مع عرض أبعاد العرض والارتفاع، ثم يكشف الصورة داخل `.cw-avatar-inner`.
     - `draw-type`: يتحرك المؤشر ويرسم إطار المساحة، ثم يكتب النصوص الموجودة داخل العناصر الفرعية التي تحمل السمة `data-cw-type` تدريجياً مع مؤشر كتابة يومض (`.cw-caret`) ودعم اللغتين عبر `data-ar` و`data-en`.
     - `draw-card`: يتحرك المؤشر إلى زاوية البطاقة، يسحب إطارها مع القياسات، ثم يكشف محتواها داخل `.cw-card-content`.
     - `clone-card`: يتحرك المؤشر إلى البطاقة المصدر المحددة في `data-cw-clone-from="#source-id"`، ويسحب نسخة مرئية منها إلى موقع البطاقة الجديدة مع إظهار خطوط المحاذاة الأفقية وقياس المسافة بالبكسل قبل كشف محتوى البطاقة الثانية.

### مثال تطبيقي سريع

```html
<!-- عنصران يعملان بالتوازي في الخطوة 1 -->
<div class="cw-avatar-slot cw-pending"
     data-cw-item data-cw-step="1" data-cw-action="draw-image" data-cw-cursor="cyan">
  <div class="cw-avatar-inner">...</div>
</div>

<div class="cw-title-box cw-pending"
     data-cw-item data-cw-step="1" data-cw-action="draw-type" data-cw-cursor="violet">
  <h1 data-cw-type data-ar="عنوان تجريبي" data-en="Sample Heading"></h1>
</div>

<!-- بطاقة أولى في الخطوة 2 تليها بطاقة منسوخة منها في الخطوة 3 -->
<article id="my-card-1" class="cw-card cw-pending"
         data-cw-item data-cw-step="2" data-cw-action="draw-card" data-cw-cursor="amber">
  <div class="cw-card-content">...</div>
</article>

<article class="cw-card cw-pending"
         data-cw-item data-cw-step="3" data-cw-action="clone-card"
         data-cw-clone-from="#my-card-1" data-cw-cursor="amber">
  <div class="cw-card-content">...</div>
</article>
```
